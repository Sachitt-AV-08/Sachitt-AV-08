# Hey, I'm Sachitt

Building **CODA** -- an operating system for AI that runs on your own hardware.

No cloud. No API keys. No subscription. Just your machine, your data, your rules.

---

## What I'm Building

**CODA** is a connected ecosystem of 25+ components that together form a local-first AI operating system:

```
BHAASM (2.2B neural brain) -> AGNI (creates) + VEDA (validates)
       |
       +-> CODA OS (desktop/web/mobile)
       +-> CODA Forge (3D reconstruction from phone video)
       +-> CODA Genesis (image/video/3D generation)
       +-> VIJAY (voice assistant, 33 tools)
       +-> COSMIC (10 composable device projects)
       +-> Cloud GPU training (Kaggle/Modal/Colab/Lightning)
```

**~296,000 lines of real, working code.** 5 languages. All local. All functional.

## Design Principles

1. **Local-first** -- Your hardware, your data, no cloud dependency
2. **Composable** -- Each component works standalone, combine for more power
3. **Agent-driven** -- AGNI creates, VEDA validates, VIJAY interacts
4. **Self-improving** -- TRISHUL learning loop: generate, evaluate, improve, repeat
5. **Multi-accelerator** -- CPU + GPU + iGPU + NPU, right tool for each job
